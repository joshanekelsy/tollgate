## Stop conditions

Stop adding features when any occurs:

- The real OpenAI call has not passed.
- A key, prompt, or response appears in storage or logs.
- Project A can read Project B.
- The dashboard cannot show the first row.

Fix that condition before touching landing-page polish or communication.

- Core value reaches the dashboard through one complete flow.
- Security and estimate limitations are visible.
- Product is deployed to Vercel and source is pushed to public GitHub.
